# CanvasPro Codex++ v2.3.1-canvaspro.1

本版基于 [BigPizzaV3/CodexPlusPlus v2.3.1](https://github.com/BigPizzaV3/CodexPlusPlus/releases/tag/v2.3.1)，源码提交 `7d7832edfb93afbcc9759c8d970b07cbcb27ae44`。保留上游作者署名、AGPL-3.0-only 和第三方声明。

- 同步长会话请求包含坏字节时的转发修复、切换模型家族后的兼容处理、过期多开实例清理及使用模式记忆。上游网关登录权限更新后，已有网关账号可能需要在 Codex++ 内重新登录。
- 新首页保留 CanvasPro 填 Key 即用的入口、运行状态和常用工具。选择「只用增强功能」时隐藏接入面板，避免改变用户交给其它工具管理的供应商配置。
- 继续默认使用 `https://api.canvasproai.com/v1` 和 Responses / Pure API。2026-11-07 核对公开目录，`gpt-6.1-sol`、`gpt-6-sol`、`gpt-6-astra`、`gpt-5.6-sol` 四款预设仍在列。
- 更新微信「画布&api服务群」二维码，截图标注 **2026 年 11 月 14 日前有效**。原图随源码和安装包提供。

下载 Windows x64 setup / ZIP 或 Mac 通用 DMG（Intel / Apple Silicon）。官方 Codex 桌面应用需要另行安装；完成使用模式选择后，在首页填写本站 Key 并点击「保存并启动 Codex」。若已启用 Codex 网关，先按提示断开并还原，避免覆盖现有配置。详见[使用教程](https://github.com/Namm-star/CanvasPro-CodexPlusPlus/blob/main/docs/CANVASPRO.md)。

Mac 使用 ad-hoc 签名，未经过 Apple 公证。构建、回归和附件来源记录见[开发记录](https://github.com/Namm-star/CanvasPro-CodexPlusPlus/blob/main/docs/development/CANVASPRO_HISTORY.md)。没有用真实 Key 发出付费模型请求。
