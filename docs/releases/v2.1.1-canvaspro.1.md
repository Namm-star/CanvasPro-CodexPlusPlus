# CanvasPro Codex++ v2.1.1-canvaspro.1

本版同步 [BigPizzaV3/CodexPlusPlus v2.1.1](https://github.com/BigPizzaV3/CodexPlusPlus/releases/tag/v2.1.1)，上游源码为 `97278ddf11570a6cae7297379c1354a63dfeb13d`。保留原作者 BigPizzaV3、贡献者历史、AGPL-3.0-only 和第三方声明；CanvasPro 定制版由 Namm-star 独立维护。

## 本次更新

- 从上次 v1.9.0 基线同步 663 个上游提交，包含新版网关、多供应商路由和 Key 管理，以及 Codex / Claude 增强的后续修复。
- 同步旧版 macOS 管理界面黑屏修复、Codex 26.10 中文界面适配、长推理与上下文压缩的超时处理，以及更醒目的「启动 / 重启 Codex」入口。
- 总览首页和 Codex 概览均保留「CanvasPro New API」入口。填写本站 Key、选择模型后保存并启动，无需手动填写地址。新网关能力可按需使用，CanvasPro 快速入口继续使用直接供应商配置。
- 适配新版下拉选择和启动结果：配置失败不启动；官方 Codex 启动失败或取消时保留输入，供修正后重试；已有 Key 继续复用。
- 默认接口为 `https://api.canvasproai.com/v1`，使用 Responses / Pure API；预设 `gpt-6.1-sol`、`gpt-6-sol`、`gpt-6-astra`、`gpt-5.6-sol`。2026-10-29 重新核对本站公开目录，四款模型仍在列，菜单仍为静态文本预设。
- 更新微信「画布&api服务群」二维码，原图随安装包和源码提供；截图标注 **2026 年 11 月 5 日前有效**。

## 下载与使用

- Windows x64：`CanvasPro-CodexPlusPlus-2.1.1-canvaspro.1-windows-x64-setup.exe`；也提供 ZIP。
- Mac Intel / Apple Silicon：`CanvasPro-CodexPlusPlus-2.1.1-canvaspro.1-macos-universal.dmg`。将可见的 `Codex++.app` 拖入 Applications；隐藏的旧管理工具壳供旧更新器兼容。
- 完整对应源码：`CanvasPro-CodexPlusPlus-2.1.1-canvaspro.1-source.zip`。安装包、源码及两平台构建清单对应同一发布标签，附 SHA-256 校验文件。

需先另行安装官方 Codex 桌面应用。在总览「CanvasPro New API」中填写自己申请的 Key，选择模型，点击「保存并启动 Codex」。Key、余额、权限和常见问题见[完整教程](https://github.com/Namm-star/CanvasPro-CodexPlusPlus/blob/main/docs/CANVASPRO.md)。模型调用正常计费，不要向群聊、日志或 Issues 发送完整 Key。

已有 v1.9.0 定制版可检查本仓库更新或手动安装。仍使用首发 v1.5.0 的用户需手动升级一次，该旧版内置的更新源不属于本定制仓库。保留原配置、供应商和会话，不要为升级清空用户数据。
