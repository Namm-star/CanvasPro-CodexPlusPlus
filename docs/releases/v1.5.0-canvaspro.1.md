# CanvasPro Codex++ v1.5.0-canvaspro.1

这是基于 [BigPizzaV3/CodexPlusPlus](https://github.com/BigPizzaV3/CodexPlusPlus) 的 CanvasPro 定制版。原作者为 [BigPizzaV3](https://github.com/BigPizzaV3) 及上游贡献者，启动器与管理工具的主体能力来自原项目，感谢他们的工作。保留 AGPL-3.0-only、原版权和第三方声明；本定制版独立维护，不代表原作者对 CanvasPro 服务的背书。

## 本版变化

- 默认供应商为 CanvasPro New API，地址为 `https://api.canvasproai.com/v1`，使用 Responses 协议。
- 首页填写用户自己的 CanvasPro API Key，点击「保存并启动 Codex」即可完成配置。
- 默认 `gpt-6.1-sol`，另可选择 `gpt-6-sol`、`gpt-6-astra`、`gpt-5.6-sol`。清单来自 2026-10-02 的本站公开目录。
- 已有供应商继续保留；配置保存失败时不会启动 Codex。
- 安装包附带使用说明、原作者署名、AGPL 许可证和第三方声明。

## 使用

1. 先安装官方 Codex 桌面应用；本工具是外部启动器，不内置官方应用。
2. 安装本页的 Windows x64 `setup.exe`，打开「Codex++ 管理工具」。
3. 在 [CanvasPro 密钥页](https://api.canvasproai.com/keys) 创建自己的 API Key，填写后点击「保存并启动 Codex」。

本次先提供经过本地编译和解包核对的 Windows 安装包。macOS Intel / Apple Silicon 的构建流程已保留，可下载平台以实际附件为准。安装包和对应完整源码一起提供；重新分发时请同时提供源码与许可证。
