# CanvasPro Codex++ v1.9.0-canvaspro.1

本版同步 [BigPizzaV3/CodexPlusPlus v1.9.0](https://github.com/BigPizzaV3/CodexPlusPlus/releases/tag/v1.9.0)（`a5f531d0d2d510a984890f26fdbbc98d995c12ad`），保留原作者 BigPizzaV3 及贡献者署名、AGPL-3.0-only 和第三方声明。CanvasPro 由 Namm-star 独立维护，原作者不为本站服务背书。

## 本次更新

- 从首发的 v1.5.0 基线同步上游 281 个提交：模型目录、Responses / 工具调用、供应商配置修复，以及模型聚合、Codex 多开、用量状态栏等增强。
- 继续默认接入 `https://api.canvasproai.com/v1`。填写自己的 CanvasPro Key，选择 `gpt-6.1-sol`、`gpt-6-sol`、`gpt-6-astra` 或 `gpt-5.6-sol`，点击「保存并启动 Codex」。2026-10-15 重新核对公开目录，四款预设仍在列。
- 采用新版单应用结构；Windows 只安装一个 `Codex++` 程序，Mac 提供同时支持 Intel / Apple Silicon 的 universal DMG。
- 更新源、项目及反馈入口改为 CanvasPro 仓库；修复只改 `canvaspro` 修订号时无法识别新版本的问题。
- 适配新版配置正文持久化，未填写 Key 前保存偏好也能保留本站地址；适配新版纯 API 的本机 provider token 鉴权。
- 修复界面操作闭包保留旧“正在切换”状态，导致保存失败后再次尝试被拦截的问题。

## 下载与升级

- Windows x64：`CanvasPro-CodexPlusPlus-1.9.0-canvaspro.1-windows-x64-setup.exe`。
- Mac Intel / Apple Silicon：`CanvasPro-CodexPlusPlus-1.9.0-canvaspro.1-macos-universal.dmg`。将可见的 `Codex++.app` 拖入 Applications；隐藏的旧管理工具壳仅供旧更新器迁移。
- 完整对应源码：`CanvasPro-CodexPlusPlus-1.9.0-canvaspro.1-source.zip`。分发安装包时同时提供源码和许可证。

从 `v1.5.0-canvaspro.1` 首次升级，请从本页手动下载安装包。旧二进制仍内置上游更新地址，安装本版后才会使用 CanvasPro 更新源。关闭旧 Codex++ 后安装新版，已有应用身份、配置目录和供应商迁移逻辑继续保留；不要清空用户 Key 和会话。

官方 Codex 桌面应用仍需另行安装。打开新版 `Codex++` 管理界面，保存 Key 后启动官方 Codex；已有 Key 可复用，不需要反复填写。[完整申请与使用教程](https://github.com/Namm-star/CanvasPro-CodexPlusPlus/blob/main/docs/CANVASPRO.md)。

## 验证与限制

- 前端 625 项通过，1 项上游跳过；TypeScript 与 Vite 生产构建通过。
- CanvasPro 原生配置 5 项、更新器 12 项回归通过；生产前端 + 本地模拟 Tauri IPC 的七项接入检查通过，包括保存失败后的重试和已保存密钥复用。
- Windows 本地完整 Rust 回归 2233 通过、10 项上游忽略；符号链接权限不足的上游测试 `app_paths_resolves_portable_current_link_to_directory_version` 单独跳过。原测试保留，过程及环境例外见开发记录。
- 发布工作流核对各平台安装包结构、同一源码提交及 GitHub 附件 SHA-256，齐备后公开。每个平台提供构建清单和校验文件。
- Mac 使用 **ad-hoc 签名，未经过 Apple 公证**。上游证书不属于本定制仓库。若 macOS 拦截，请参考 [Apple 官方说明](https://support.apple.com/102445)。
- 没有使用真实 Key 发出付费模型请求，未声称已验收用户机器上的官方 Codex 端到端调用。
